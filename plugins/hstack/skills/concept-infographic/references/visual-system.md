# Visual system

Read alongside [the bundled example](../assets/bradley-terry-example.png). These are practical design defaults, not measured reproduction tolerances. The example uses a vertical calculation; comparisons and other concepts can use different layouts with the same visual language.

## What to preserve

- A plain, direct title with heavy sans-serif type, a restrained teal edge accent, and a loose blue underline.
- White page with generous margins; lightly tinted rounded panels outlined with muted color.
- Near-black labels and strokes, with warm terracotta and cool teal as the main semantic colors. Use a small amber highlight only when it identifies the changing value or active object.
- Simple flat geometric drawings with a light hand-drawn feel. Sparse shadows, no photorealistic texture, glossy 3D treatment, or ornamental illustration.
- Black circular step markers with white numerals. Short action labels introduce a visual operation.
- One shared example or concrete anchor. The same entities keep their labels, shape, and color as they move through the explanation.
- Thin directional arrows and clearly routed loops. Arrows express a specific operation, relationship, or sequence.
- A distinct outcome area. Use snapshots only for a real sequence; use an interpretation, example result, or boundary cases for static concepts.

## Practical starting values

| Element | Default |
|---|---|
| Canvas | Portrait, roughly 4:5; change aspect ratio when the content benefits |
| Page | White `#FFFFFF` |
| Text and primary strokes | Near-black `#171918` |
| Warm panel / accent | Cream `#FCF7F1` / terracotta `#AD604A` |
| Cool panel / accent | Pale mint `#F1F8F6` / deep teal `#286F66` |
| Highlight | Amber `#F1B75C` |
| Title accent | Blue `#2C89B7` and teal `#2AA888` |
| Copy | Usually 80–160 displayed words; simplify if cramped |
| Steps | Usually 3–5 meaningful operations |
| Type hierarchy | Title about 1.6–2 times body labels; section labels about 1.2–1.4 times body |

These colors are starting values rather than exact sampled brand values. Prioritize readable text over matching pale strokes. Maintain labels/shape differences as well as color. At a 1080-pixel-wide export, start around 28–34 pixels for main labels; verify at the intended display size rather than treating that range as sufficient proof of readability.

## Layout adaptation

Comparison panels should align comparable steps and use the same initial conditions. A single mechanism may instead use stacked cards, a centered path, or a wide flow. A mathematical explanation can retain soft panels and step markers while showing one equation at a time. A graph relationship can keep matching colors for corresponding entities across both diagrams.

Do not force a warm bad / cool good judgment. Colors can distinguish roles or cases; identify their meaning. Avoid implying that every paper contribution replaces an inferior baseline.

## Prompt ingredients

Describe the output as an original educational infographic with clean vector-like geometric illustrations, lightly hand-drawn strokes, strong typographic hierarchy, rounded pastel panels, numbered steps, visible operations, and an explicit takeaway. Name the style image as a visual reference only. Include exact copy and spatial relationships from the content brief. Exclude unrelated example content and any publisher branding from user-supplied references.
