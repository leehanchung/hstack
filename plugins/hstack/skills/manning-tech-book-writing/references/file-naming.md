# File Naming Conventions

## Chapter and Related Files

Use the following file naming convention:

### Format
- `chXX_externalID` - for chapters (use leading zeros for chapters 01-09)
- `ch01_davis5` - example for chapter 1
- `MQR_davis5` - for MQR (manuscript quality requirements)
- `TOC_davis5` - for table of contents
- `APP_B_davis5` - for appendices
- `PART1_davis5` - for part divisions
- `FM_davis5` - for front matter

### Important Rules
- Lead with a zero for chapters 01-09 (ch01, ch02, etc.) for correct numerical ordering
- The external ID and author's last name are usually the same but not always
- Use underscores, never spaces
- Check with Development Editor if unsure about external ID

## Figure Naming

### Numbered Figures
- Format: `chXX_F0YY_ExternalID`
- Example: `ch01_F011_davis5`

### Unnumbered Figures
- Format: `chXX_UN0Y_ExternalID`
- Example: `ch01_UN01_davis5`

### Special Sections
- Introduction: `INTRO_F01_ExternalID`
- Preface: `PREF_F01_ExternalID`
- Inside Front Cover: `IFC_F01_ExternalID`
- Inside Back Cover: `IBC_F01_ExternalID`
- Appendix A: `APPA_F01_ExternalID`
- Appendix B: `APPB_F01_ExternalID`
